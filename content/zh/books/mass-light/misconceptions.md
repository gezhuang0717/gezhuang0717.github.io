| 常见说法 | 更准确的表述 |
|---|---|
| “标准模型一共有 61 种基本粒子。” | 粒子总数取决于如何计颜色、反粒子和内部自由度；不存在唯一的“61”计数。 |
| “三代就是按发现时间分的。” | 代是规范量子数结构的重复，不是发现年份。 |
| “所有玻色子都是传力粒子。” | 规范玻色子介导规范相互作用；希格斯 是自旋 0 玻色子，但不是一种普通规范力的传播子。 |
| “希格斯 给粒子输送能量，所以产生质量。” | 希格斯 非零真空期望值使相互作用项转化为质量项。 |
| “人体 99% 质量就是胶子结合能。” | 核子质量主要来自非微扰 QCD 动力学；严格分解依赖尺度和方案。 |
| “手征破缺导致夸克禁闭。” | 二者相关但不同，不能互相等同。 |
| “QCD 解禁闭要到 GUT 能标。” | QCD 热交叉约在 156 MeV，重离子实验可研究 QGP。 |
| “光电效应和光强完全无关。” | 阈值由频率决定；超过阈值后光强通常改变光电子计数/光电流。 |
| “光子是宇宙最小能量单位。” | {{< reader-math "inline" >}}E=h\nu{{< /reader-math >}}，光子能量没有统一非零下限。 |
| “所有有质量粒子都会衰变。” | 电子稳定；稳定性取决于守恒律和可用衰变道。 |
| “光只有运动质量。” | 现代语言：光子不变质量为零，但有能量和动量。 |
| “光子自己看到整个宇宙瞬间结束。” | 光线固有时为零，但不存在光子静止参考系。 |
| “大爆炸证明宇宙从无中生有。” | 热大爆炸描述早期高温高密和膨胀历史，不等于证明绝对起源。 |
| “多元宇宙已经是标准物理事实。” | 属于不同理论框架下的推测或诠释，尚无直接确认。 |
