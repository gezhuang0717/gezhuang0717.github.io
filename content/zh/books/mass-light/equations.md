## 相对论

{{< reader-math "block" >}}E^2=p^2c^2+m^2c^4,{{< /reader-math >}}

{{< reader-math "block" >}}ds^2=c^2dt^2-d\mathbf x^2,{{< /reader-math >}}

{{< reader-math "block" >}}p_\mu p^\mu=m^2c^2.{{< /reader-math >}}

## 量子关系

{{< reader-math "block" >}}E=h\nu=\hbar\omega,{{< /reader-math >}}

{{< reader-math "block" >}}p=\frac{h}{\lambda}=\hbar k.{{< /reader-math >}}

## 电磁学

{{< reader-math "block" >}}\partial_\mu F^{\mu\nu}=\mu_0J^\nu,{{< /reader-math >}}

{{< reader-math "block" >}}\partial_{[\lambda}F_{\mu\nu]}=0.{{< /reader-math >}}

## 电弱对称性破缺

{{< reader-math "block" >}}V(\Phi)=-\mu^2\Phi^\dagger\Phi+\lambda(\Phi^\dagger\Phi)^2,{{< /reader-math >}}

{{< reader-math "block" >}}m_W=\frac{gv}{2},{{< /reader-math >}}

{{< reader-math "block" >}}m_Z=\frac{v}{2}\sqrt{g^2+g'^2},{{< /reader-math >}}

{{< reader-math "block" >}}m_f=\frac{y_fv}{\sqrt2}.{{< /reader-math >}}
